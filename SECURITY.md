# Security policy

Do not open a public issue for a suspected vulnerability that could risk user
funds, reveal secrets, bypass timelocks, violate taker-first ordering, or break
atomicity.

Until a dedicated disclosure mailbox is published by the project owner, contact
the primary engagement contact listed in accepted proposal
[logos-co/rfp#112](https://github.com/logos-co/rfp/issues/112). Include affected
commit, reproduction steps, impact, and a safe communication channel.

No production deployment is supported before Milestone 7's third-party review
and remediation are complete.
